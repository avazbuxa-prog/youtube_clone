## 📖 Loyiha haqida

**YouTube Clone** — YouTube bosh sahifasining tashqi ko'rinishini takrorlovchi front-end loyiha. U Git va GitHub darsi doirasida do'stlar bilan birgalikda yaratilgan. Loyiha faqat **HTML** va **CSS** da yozilgan, JavaScript ishlatilmagan, shuning uchun hozircha bu statik maket (video ijro etilmaydi, qidiruv ishlamaydi).

## ✨ Imkoniyatlar

- 🌑 **Qorong'i mavzu** (`#0f0f0f` fon), asl YouTube'dagidek
- 📌 **Sticky header**: sahifa aylantirilganda tepada qotib turadi
  - ☰ menyu tugmasi va YouTube logotipi
  - 🔍 qidiruv paneli va 🎤 mikrofon tugmasi
  - 🎥 video, 🔔 bildirishnoma ikonkalari va profil avatari
- 📂 **Sticky yon panel (sidebar)**: Bosh sahifa, Shorts, Obunalar, Kutubxona, Tarix
- 🏷 **Kategoriyalar qatori**: Barchasi, Dasturlash, Musiqa, O'yinlar, Texnologiyalar (gorizontal aylantiriladi)
- 🎞 **Video kartochkalar to'ri (grid)**: kichik rasm (thumbnail), davomiylik belgisi, kanal avatari, sarlavha, kanal nomi, ko'rishlar soni va vaqt
- ✨ **Hover effektlari**: tugmalar rangi o'zgaradi, thumbnail ustiga kursor olib borilganda yengil kattalashadi
- 🧩 Sarlavha 2 qatordan oshsa, avtomatik qisqartiriladi (`line-clamp`)
- 📐 `auto-fill` grid: ustunlar soni ekran kengligiga qarab o'zgaradi

## 🛠 Texnologiyalar

| Texnologiya | Vazifasi |
|-------------|----------|
| **HTML5** | Sahifa tuzilishi (header, aside, main) |

| **Picsum Photos** | Namuna rasmlar (thumbnail va avatarlar) |

## ⚙️ Ishga tushirish

```bash
# 1. Repozitoriyni klonlash
git clone https://github.com/avazbuxa-prog/git-darsi-3-.git

# 2. Papkaga kirish
cd git-darsi-3-
```

Keyin `index.html` faylini brauzerda oching. Server yoki qo'shimcha o'rnatish kerak emas.

> ℹ️ Ikonkalar va rasmlar internetdan yuklanadi, shuning uchun ularni ko'rish uchun internet kerak.
